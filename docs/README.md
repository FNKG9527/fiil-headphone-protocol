## 我想理解整套协议

**读** [`PROTOCOL_FIIL.md`](PROTOCOL_FIIL.md)

这是规格总纲。它把同一副耳机上的**三套命令空间**放在一起讲清楚：

| 命令空间 | 特征 | 用在哪些机型 |
|---|---|---|
| **GAIA** | 16 位命令字（`0x02xx` / `0x07xx`），帧以 `0xFF` 打头 | 老款主力机型 |
| **Mate** | `classifyId + cmdId` 两个 8 位值，帧以 `0x00` 打头 | F045 ~ F053 这一代 |
| **豆包 0x55AA** | 独立的语音业务帧 | earType 47 / 48 |

重点章节：**§0 结论速览**、**§3.12 GET 与 SET 是两套完全不同的帧语义**（实战最大坑）、**§5 机型与路由**。
